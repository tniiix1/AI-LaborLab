Допущения модели — как считаются значения

Для каждого сценария задан условный «прогресс технологий» p (от 0 до 1) на 2026, 2030 и 2040 годы. Между узлами значения интерполируются линейно.

Каждый критерий X сдвигается к 10 на долю своего «запаса»: X(t) = X₂₀₂₆ + (10 − X₂₀₂₆) · k · p. Коэффициенты k: D — 0,80 (задачи всё чаще можно цифровизировать), C — 0,35 (растёт роль анализа и нестандартных решений), A — 0,30 (растёт ответственность за проверку результатов), H — 0,20 (растёт роль объяснения и общения), R — 0 (рутинность считается неизменной).

Затем индексы пересчитываются по обычным формулам: ИТП = (R + D + (10 − H) + (10 − A)) / 4, ИНЧ = (H + A + C) / 3.

Ограничения. Исходные оценки профессий — предварительные демонстрационные значения. Модель не учитывает спрос на труд, законы, экономику, обучение кадров и конкретные технологии; коэффициенты — договорённость для сравнения сценариев, а не результат статистического исследования. Поэтому результат нельзя использовать как прогноз.

Цель и задачи

Цель проекта — исследовать, как искусственный интеллект может менять содержание профессиональных задач, и создать интерактивный инструмент для сравнения профессий по единой системе критериев.

Авторская модель оценки профессий

Каждая профессия оценивается по пяти критериям по шкале от 0 до 10. Значения используются для расчёта двух индексов: ИТП и ИНЧ. Модель помогает сравнивать профессии в рамках выбранных критериев, но не является точным прогнозом исчезновения рабочих мест.

Пять критериев

  • R — рутинность работы: насколько часто повторяются однотипные действия.
  • D — цифровизируемость задач: какая часть задач потенциально может выполняться цифровыми системами.
  • H — человеческое взаимодействие: насколько работа зависит от общения и доверия.
  • A — ответственность за результат: насколько серьёзными могут быть последствия ошибок.
  • C — творчество: насколько часто нужны новые решения и нестандартное мышление.

Формулы ИТП и ИНЧ

ИТП =R + D + (10 − H) + (10 − A)4
ИНЧ =H + A + C3

Оба индекса находятся в диапазоне от 0 до 10. Чем выше ИТП, тем выше потенциал трансформации задач по данной модели. Чем выше ИНЧ, тем большую роль играют человеческое взаимодействие, ответственность и творчество.

Ограничения и качество данных

Оценки, включённые в первоначальную базу, являются предварительными демонстрационными значениями и не должны восприниматься как официальная статистика или экспертный консенсус. Для повышения объективности нужно описать типичные задачи каждой профессии, привлечь независимых оценщиков и сравнить их результаты.

Пользовательские оценки хранятся отдельно от демонстрационных. Сохранение в браузере работает только на текущем устройстве и в текущем браузере.

История оценок

Когда пользователь сохраняет новую оценку, сайт добавляет запись в локальную историю. Это позволяет сравнить два измерения, но само по себе не доказывает, что профессия реально изменилась: разница может отражать мнение другого оценщика.
